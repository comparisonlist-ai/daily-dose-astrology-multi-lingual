Install AstroSeek App

Install Daily Rashifal App on your phone for convenient access to your daily horoscope.

How to install

  1. Tap the three-dot menu (⋮) at the top-right corner of Chrome.
  2. Look for Install app, Install, or Install and create shortcut.
  3. If none of these options appears, look for Add to Home screen.
  4. Follow the on-screen instructions to complete the installation.

If none of these options is available, don't worry. You can return to the horoscope page using the link below.
